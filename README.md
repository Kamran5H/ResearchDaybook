# Research Daybook

A **single-file research journal** — one `daybook.html` you open in any browser. All entries live in the browser's `localStorage`, so there's no server, no account, and no data ever leaves your machine.

## Use it

Just open `daybook.html`. That's it.

For a desktop app feel on Windows, run the included launcher:

- `Install (run once).cmd` — sets up a desktop shortcut / scheduled launch
- `launch.vbs` — opens the daybook in app mode
- `Install-Task.ps1` — optional scheduled-task installer

## Why single-file

- Zero dependencies, zero setup
- Fully offline and private (localStorage)
- Trivial to back up — it's one HTML file
